PART A — CSIF codec (pure module, zero Tkinter, do this first)
Grammar: header occupies a whole line.
  "@@Speaker"        -> speaker
  "@@_"              -> narration (import also accepts a bare "@@")
  "@@{playername}"   -> literal player token
  "@@!title" / "@@!subtitle" / "@@!summary" -> Box 0, only before the first dialogue header
  "@@#N|Speaker"     -> sparse, 1-based, ONLY for non-contiguous export
Body: lines until the next header or EOF. Escape a body line starting with @@ as \@@.
Exactly one LF before the next header is a delimiter; all other newlines are content.
Accept LF/CRLF/CR, strip BOM, emit LF. Strip only an OUTER Markdown code fence, with a warning.
API: serialize(doc, *, scope, box_indices, include_metadata="auto"), parse(text), sniff_format(text), apply_to_document(doc, result, *, mode, start_box_index, overflow, apply_speakers).
Modes: "insert" (create boxes), "replace" (overwrite from start), never a silent positional fallback in sparse mode.
Reject mixed/duplicate/missing/out-of-range sparse addressing. Sanitize speakers (strip Cf/Cc, map NBSP/ideographic space).
Legacy INPUT adapters: "=== [BOX:n|Speaker:x] ===", triple-enter, paragraphs, lines. Output is always CSIF.

PART C — box clipboard speaks CSIF (the user's request)
1. on_box_copy emits CSIF via serialize(). Contiguous selection -> numberless. Non-contiguous (Select Box mode) -> sparse @@#N|Speaker. Box 0 selected -> @@! metadata headers. Store a BoxSnapshot plus the emitted CSIF text as the internal snapshot.
2. on_box_paste parses the clipboard with sniff_format/parse and applies mode="insert" after the active box, preserving speakers, converting narration to tag records, in ONE undo batch. Show a minimal confirm dialog: block count, first three speakers, insertion point. Never insert headers into dialogue text.
3. on_copy_script / on_paste_cross_box use the SAME codec with mode="replace" from the active box. Remove every triple-enter and "=== [BOX:" emitter.
4. Plain Ctrl+V inside an editor: if sniff_format reports CSIF, show a chooser (paste as text / paste across boxes / insert as new boxes / cancel). Default to cancel on ambiguity.
5. on_copy_ai_prompt emits the same CSIF body with a short header:
   "Translate JA->EN. Keep lines starting @@ unchanged. Preserve NGUI tags, {playername}, {0}. Same block count and order. Never begin a line with @@; escape it as \@@. Output only the script."
